# Third-party dependencies

This bundle declares these direct Node.js runtime dependencies. npm installs them separately and retains their package metadata and license files:

| Package | Version | Declared license | Source |
| --- | --- | --- | --- |
| @mozilla/readability | 0.6.0 | Apache-2.0 | https://github.com/mozilla/readability |
| jsdom | 30.1.3 | MIT | https://github.com/jsdom/jsdom |

The lockfile records the complete transitive Node.js dependency set. Consult the installed packages for their full license texts and notices.

Optional Python workflows use Requests (Apache-2.0), Pillow (MIT-CMU), Beautiful Soup (MIT), and Python-Markdown (BSD-3-Clause). These libraries are installed separately, not copied into the bundle. See each installed distribution's license for authoritative terms.

The migration preserves the existing skill files, reference documents, and icon. It does not establish new authorship or licensing for those resources. The package remains private and UNLICENSED; verify the provenance and permissions of existing resources and select a project license before any public distribution.
